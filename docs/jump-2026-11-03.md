# Mod+N 跳转验收

2026-11-03，用户指定快捷键 `Mod+N`，用于查看已完成任务的第一个窗口。

## 行为

新增 `agent-done jump`，按完成时间从早到晚选择尚未查看、仍在终端中显示的会话。通过既有会话映射取得 niri 窗口 ID，调用 `focus-window --id`。实际聚焦后由原有焦点监听清除提醒，再按一次选择下一个。没有目标时不切换窗口。

跳转只选择已成功完成的会话。等待授权、结构化回答、执行失败、已查看、隐藏会话、失效进程和关闭窗口均跳过。失败的跳转不提前清除提醒，选择依据与窗口当前行列无关。

    spawn "/home/csc/.local/bin/agent-done" "jump";
}
